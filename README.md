# README

This repo contains the macOS-centric, Node-based scaffold (using Gulp v5) I use to build a presentation deck using Deckset for macOS. In this case, the deck is for a talk titled _How I Employ and Expand on David Agans’ 9 Debugging Rules to (try to) Repair Anything_ at Repurposeful Ancestry Lab’s 21 November 2026 event at the Brooklyn Library's Flatbush branch.

## 1. Install Node Modules

```bash
npm i
```

## 2. Build the Deck and Watch for Changes

```bash
gulp
```
