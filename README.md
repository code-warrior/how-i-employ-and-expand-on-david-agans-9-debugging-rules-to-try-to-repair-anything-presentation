# README

This repo contains the macOS-centric, Node/Gulp-based scaffold I use to build a presentaion deck using Deckset for macOS. In this specific case, the deck is for a talk titled _How I Employ and Expand on David Agans’ 9 Debugging Rules to (try to) Repair Anything_ at Repurposeful Ancestry Lab’s 21 November 2026 event at the Flatbush branch of the Brooklyn Library.

## 1. Install Node Modules

```bash
npm i
```

## 2. Build the Deck and Watch for Changes

```bash
gulp
```
