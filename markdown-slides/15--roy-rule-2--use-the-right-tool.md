## Use the Right Tool (Roy Rule 2)

> No toothpicks in place of a punch; no scythe in place of a utility knife

* If the tool doesn’t fit, don’t force it
* You need a larger screwdriver, but use a smaller one, expect to ruin the thread
* You need a punch but instead use a multimeter probe, you’re going to break it
* Now the item is slightly more damaged
* Usually the result of rushing
